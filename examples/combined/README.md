# ESP + Bhop + Triggerbot

Пример одной DLL для локальной игры с ботами: ESP, автопрыжок и
триггербот настраиваются в общем меню. При открытом меню автопрыжок и
автострельба приостановлены.

Сборка: `cargo build -p example-combined --release --target i686-pc-windows-msvc`.
DLL: `target/i686-pc-windows-msvc/release/example_combined.dll`.

* `Insert` — открыть или закрыть меню.
* Для автопрыжка задайте в консоли `bind mwheelup +jump`, включите Bhop в
  меню и удерживайте пробел.
* Триггербот по умолчанию выключен; после включения он работает при удержании
  `Mouse5`. Это условие можно отключить в меню.
* `unload_combined` — остановить мод; DLL при этом остаётся загруженной.

Не загружайте одновременно отдельные моды ESP, bhop или triggerbot: эта DLL
уже содержит их механику и перехваты.
