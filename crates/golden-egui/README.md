# golden-egui

Интеграция `egui` и `egui_glow` с Gold Client для 32-битного Windows-клиента.
Пример находится в `examples/egui`.

```powershell
cargo build -p example-egui --release --target i686-pc-windows-msvc
```

Результат: `target/i686-pc-windows-msvc/release/example_egui.dll`. После
инъекции на сервере нажмите Insert, чтобы открыть или закрыть меню. Команда
`egui_menu` тоже переключает меню; `unload_egui` останавливает мод, но по
правилам SDK не освобождает образ DLL.

Установка асинхронная: детур отрисовки ставится из первого `StudioDrawPlayer`,
поэтому до появления отрисованного игрока меню недоступно. Одновременно
поддерживается только один мод с этой интеграцией; другие моды выгружайте в
порядке, обратном загрузке. Работа в конкретной конфигурации игры и драйвера
должна быть проверена в игре.

Для своего мода вызовите `golden_egui::install()`, сохраните возвращённый
объект до выгрузки и задайте интерфейс через `golden_egui::set_ui`. Клавиша
назначается через `set_toggle_key`, видимость — через `set_visible`. Полный
пример и регистрация очистки показаны в `examples/egui/src/lib.rs`.
